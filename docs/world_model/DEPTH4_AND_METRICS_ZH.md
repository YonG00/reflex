# 四层容量对照与八步误差口径

论文§3.2式(1)对j=1..8全部自回归预测误差求和，不是只优化第8步。参考独立复现将该和除以8。当前纯状态WM训练从起点连续预测8步，`window_loss`对时间、batch与82个归一化误差分量取均值；一直包含第1..8步监督。

此前结果表中的8/32步NSE是末步误差。末态误差可用于观察漂移，不能替代窗口训练目标，也不能不加区别地与论文图3数值比较。图3图注明确state-only、nominal normalization、online policy rollout，但未明确时间归约，不能仅凭图注确定是时间累计、平均还是末态。

本次补充以下评估字段（既有state_nse保留为末态兼容字段）：

- `window_state_nse`：1..H步、batch、82分量平均；与当前纯状态训练L_state同口径。
- `window_state_nse_time_sum`：对时间求和，对batch/分量平均，等于H×窗口NSE。
- `window_state_squared_l2_time_mean`：对82分量求和，对时间/batch平均，等于82×窗口NSE。
- `endpoint_state_nse`：仅第H步，与原state_nse相同。
- `per_step_state_nse`：逐步曲线，同时提供窗口robot/box拆分与位置RMSE。

所以当前纯状态loss与“时间和、分量和”的状态损失还差H×82的常数；归一化尺度、状态定义也不同，不能拿绝对数字直接对标论文。此次保留训练loss缩放，避免把网络深度和梯度尺度同时改变。

新增试验配置`configs/world_model/state_2048x4.json`，四个隐藏层各2048，SiLU。三层默认与已训练对照保留，不静默覆盖。四层从零初始化，固定原回放、seed42、batch128、8步监督、256次更新、lr2e-4、clip1，与三层完全一致；不从三层拼接权重，不进行Actor或AMP更新。

论文：https://arxiv.org/pdf/2610.28480 ，式(1)、图3图注、表A.4。原论文动力学网络为2048×3，本次2048×4是容量实验。

## 实测结果

20项CPU测试通过。四层参数14,561,362，三层10,365,010；四层256更新及周期验证28.5秒。两者训练预算与采样一致。没有真实Actor更新。

本轮四层没有整体优于三层，只在短程箱子位置上略好。不能据单种子256更新认定深度无效或两者已收敛；也没有理由只因网络更大就替换三层基线。后续若延长训练，应让三层/四层同预算一起比较。

原验证三层8步时间累计NSE为1.652607，四层1.683027（窗口均值乘8）；新seed43分别1.865835与1.895418。它们和末态NSE是不同统计，不能相互代替。
