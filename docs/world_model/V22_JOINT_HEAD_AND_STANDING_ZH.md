# 联合终止监督与等待阶段学习修复

## 纠正对齐范围

此前 V2.1 仅对齐了部分网络、优化超参数和更新频率，终止头监督没有对齐第三方 `SuperMimic-Reproduced`：它使用真实预重置特征单独拟合 BCE，不向 WM 反传。历史结果不能称为完整复现第三方。

新配置 `joint_repaired_v22_joint_head.json`：每个有效监督窗口最多8步自回归，预测下一状态 → 同想象路径的48维终止特征 → 终止头 → 真实终止标签 BCE。不 detach。状态误差按状态维求和、有效时间步平均，BCE同样按有效时间步平均，权重1。两项共同一次 backward，并对 WM+Head 参数统一裁剪。为保留已有 Adam moments，仍保留两个不共享参数的 Adam 实例，同时 step 并同步学习率；相同超参数下等价于一个 Adam 管理两组参数，不是先训练 WM 再用真实特征训练头。

48维Reflex终止几何、Reflex状态维度及奖励仍是任务适配，不声称与第三方机器人和任务完全相同。预测特征/训练方式写入learning_contract；旧存档默认拒绝静默加载，显式 `--migrate_termination_training` 才允许这一方向迁移，并记录权重/优化器保留及恢复的有效样本数。

## 站稳优先与采样修复

发现并修复三处发射门槛：Replay想象起点、adapter `start_valid`、adapter训练 `valid`。现在有效状态可包含发射前和静止箱子；Actor从合法参考阶段的有效起点均匀有放回抽2048个。不做速度门槛，不加新的奖励或关闭碰撞。

仅删除门槛还不够：原环境每个控制步末尾会把等待箱子写回悬停位置，该写入属于已知外部事件。

- WM训练使用最多8步的有效窗口；遇悬停写入、发射、复位、终止或超时停止该窗口。等待的一步真实物理转换仍纳入训练，补齐部分不计损失。按每个窗口的有效步数归一化，避免等待样本因短窗口被除以8而降低权重。真实终止那一步仍计入BCE。
- Actor等待起点展开一个真实物理步后truncate并在pre-event状态bootstrap，不把箱子后续悬停伪装成自由物理演化。发射后继续最多32步想象。
- 独立留出环境划分不变。长期预测误差仍只评估连续真实物理窗口，不把padding当预测目标。
- 显式迁移会依据已存物理张量是否有限，重建旧Replay里的`valid/start_valid`，恢复被旧发射门槛排除的等待数据；不删除真实数据。

新增监控：Actor等待/已发射起点占比，箱子静止/运动占比（0.1m/s仅为统计阈值）；WM等待窗口占比、有效窗口长度。原接触监控保持关闭。

## 验证状态

CPU包括：BCE向WM产生非零梯度、预测终止特征与想象计算一致、旧存档显式迁移/Adam恢复、静止未发射起点可采、筛选不修改Replay、窗口不跨事件/终止、终止标签保留。最终GPU等待覆盖回归尚待核验。

先前仅联合终止修复GPU短回归已完成两次Actor、20次WM/Head更新：加权BCE到WM梯度范数0.06180，loss=state_loss+BCE；第二次Actor5.276秒。该轮尚未包含完整等待有效性修复，不能作为等待阶段通过证据。

扩大编译：整体WM+FK+Reward+Termination融合已捕获成功，但32步输出比较失败（部分观测最大差约0.026），没有放行正式训练。分模块扩大编译仍在实验，正式配置保留已验证的WM/FK编译。
