# V3 状态模型与任务逻辑迁移

旧版固定于 `archive/wm-v1-28527ba`；原 L40 第40轮存档及随机回放保持不变。新机迁移包 SHA256：`f8ff70e1fae9f8a2051796c00d829e83d8109491bb6a2589d5cb6e98410c6ded`。

## 实现

- WM 优化器与Actor/Critic独立；默认 `model_lr=2e-4`、`model_grad_clip=1`。
- 默认 `wm_kind=state`：独立的 2048×3 SiLU 动力学网络，只输出82维物理残差，只优化原归一化状态平方均值。没有 reward/memory/done 预测头。机器人70、箱子12维误差相对权重未改。
- 保留显式 `wm_kind=multitask` 用于旧结构对照；不会将旧模型参数静默载入纯状态模型。完整新存档为 version2，并校验模型、配置、物理和任务合同。
- 纯物理输入是 heading-canonical 联合状态、已核对的 pre-gimbal 关节目标及实际动力学条件。gimbal/PD/PhysX 仍是宏步闭环 plant；任务参考、raw action、奖励历史不再混入物理预测器。
- `sample_starts` 仅要求当前已发射快照合法，独立于真实未来长度；`sample` 继续严格检查连续监督窗口。参考末尾、超时、已知定时事件、重投和潜在 cradle kick 在想象中截断，不伪造外力后状态。
- `AnalyticTask` 用状态派生的机器人/箱子数据视图执行原 Torch reward/termination 函数；包含COM修正的body速度FK、原参考对齐、原权重与dt。并非重新手写几十项奖励。
- 增加旧 memory 遗漏的 `_chest_v5_persist`，与 bed/tp/rethrow/cradle 计数分别保存。原始计数与时钟解析推进，不由神经网络猜测。
- 原传感器型 `undesired_contacts` 若非零，明确标记为身体高度的地面风险代理，不能声称恢复了自碰撞/箱子接触力。当前配置中权重为零的项保持配置语义；未知解析依赖会显式失败，不能静默置零。
- model truncation/timeout 使用末个预事件状态的 Critic bootstrap；物理终止不 bootstrap。未模拟参考随机重采样和随机外力，其边界价值仍是近似，不能把预测精度等同反事实可信度。
- 纯状态模型不再受 `reward_rmse` 放行门控制；32步误差作为诊断记录，不照搬16步阈值。昂贵排序探针仅在基本物理误差检查和预热后执行。逐项梯度审计可配置为低频。
- 状态 loss 记录窗口均值与末步值，NSE与RMSE分开；物理误差包含位置每分量/三维RMSE、姿态、速度和关节。记录真实/预测输入的截断比例。

## 验证范围

当前只执行 WM 留出预测对照，不进行真实 Actor 更新、Teacher 热启动或阶段均衡。四组使用同一固定随机数据、随机种子、训练起点和固定验证窗口；激活、归一化样本、8步窗口、学习率与优化步数保持一致。

纯状态结构同时移除了任务专属输入，因此“纯状态 vs 旧多任务”是整个状态模型设计对照，不能把全部差异归因于某一个辅助 loss。需要时再做更细的消融。

CPU 测试已覆盖纯状态 loss、旧版回归、FK速度、解析历史/截断和短轨迹起点。真实 reward/termination/history parity 与 GPU 对照结果应以实际运行产物补充；不能从 CPU 通过推断真实任务已通过。

## 实测与审查

- 4090 上64环境×128步预检完成，共8,192条真实转移；全部原奖励项最大绝对差4.62e-7，终止判定及奖励历史计数一致。观测/FK误差1.75e-6，AMP特征误差2.21e-6。原样例随机策略并不覆盖长期成功抱持或所有外力边界，不能据此宣称完整任务闭环已复现。
- 首轮发现缓存时序差异：MotionCommand相对身体参考缓存可先于reset/interval写入。起点必须保存实际缓存；后续无外部事件的想象步再解析推进。已增加回归检查。
- 本轮真实Actor更新为0；CPU合成梯度测试不属于真实策略训练。
- Spec审查未发现阻塞当前WM-only对照的问题。Standards审查提出梯度统计未遮罩与manifest初值误导两项，已改为实际折扣/生存率加权贡献、已检查条数及退出时刷新实测误差。
- 真正Actor训练前，仍须补持续成功抱持、参考重采样、重投/推扰边界与动作排序验证。本轮不启用Actor。

## 固定随机回放首轮2×2结果

四组从零初始化WM和Adam，各256次更新、batch128、8步监督、SiLU、lr2e-4、clip1、seed42。相同训练/验证窗口和2048条训练归一化样本；不使用阶段均衡。表中NSE为末步归一化平方均值，箱子位置为每坐标RMSE。

| WM设计 | 参数数 | 8步NSE | 8步箱子位置 | 32步NSE | 32步箱子位置 | 训练与周期验证耗时 |
|---|---:|---:|---:|---:|---:|---:|
| 256×2 多任务 | 382,604 | 0.627629 | 4.475cm | 9.524442 | 25.645cm | 101.3s |
| 256×2 纯状态 | 312,402 | 0.563113 | 4.549cm | 7.644428 | 27.088cm | 28.7s |
| 2048×3 多任务 | 10,926,220 | 0.410081 | 3.634cm | 5.461054 | 18.089cm | 110.6s |
| 2048×3 纯状态 | 10,365,010 | 0.385651 | 3.876cm | 3.441576 | 16.354cm | 30.5s |

大容量有效；同容量去除辅助头/任务输入对归一化总误差有改善，但8步箱子位置不优于多任务版，小纯状态32步位置甚至更差，不能宣称所有指标都改善。大纯状态相对小多任务，8步NSE降低38.6%，32步NSE降低63.9%。长程误差仍明显，不据此放行真实Actor。

本轮仅一个随机种子、一个固定回放；验证集已被用于方案比较，不是最终独立测试集。256次更新也不是收敛证明。耗时含周期验证且多任务版含FK开销，不可当纯网络吞吐对比。

服务器产物：`outputs/world_model/20261105_v3_2x2/`，各组包含 `comparison.json`、`learning_curve.json`、`wm_window8_weight1.pt` 和日志。预检：`outputs/world_model/20261105_v3_parity_r3/`。
