确定性版本保留为后续试训架构。真实事件写入一致性通过；Physical WM、联合终止BCE、

## 真实事件验证

24步原生/想象调度对照，包含等待、发射、自动重投、悬停恢复、hold-init关节子集、
根速度推力、透传及真正触发的cradle扰动。
使用受控合法前缀使原有分支可达；不更改原事件概率、公式、随机采样或PhysX API参数。
扰动实际赋速10次；每步确定性Post-control与真实API写入后状态最大差0，
写入指令最大差0，事件内部状态最大差1.2e-7。优化器更新0。

发现并修复一个原生代码的可微性问题：重投前使用过的_box_lib_mask、tmult等控制张量，
随后被reset_box_throw原地更新，导致Actor backward版本错误。
只在启用梯度时对这些控制缓冲区copy-on-write，保留连续计算图；不detach，
原采样值、触发和实际写入不变。CPU执行真实reset函数体的保存张量/梯度回归通过，
GPU后续6次Actor反传均通过。

## 同数据配对设计

真实环境256个，冻结128帧/32,768条转移；H8合法窗口25,153，H32窗口3,804。
实际发射写入仅3次；不是大规模投掷/接触数据。
检查859个真实reset/参考边界，Physical目标保留、事件mask清零；14个边界仅为参考重置。
checkpoint load额外给Replay末帧加的衔接截断单独处理，不当成物理reset。

两组均从同一个V22工程bootstrap的Physical/Actor/Critic/Termination权重开始；
旧版的Post-control MLP为新初始化，不是已充分训练的旧decoder。
每组独立Replay副本和AMP判别器/Adam/真实样本buffer副本；Actor/Critic/WM优化器均新建。
每轮WM、Actor、评测固定配对采样种子；调度器自身RNG也独立重置到配对种子。
离散分支若不同，后续随机抽样的语义不保证逐agent完全一致。
每组3轮，每轮10次WM、1次Actor（2048起点/H32）、原AMP更新及Critic λ-return更新。
H8使用用户确认的记录事件条件监督；Actor与free评测不读取真实未来事件/状态。
