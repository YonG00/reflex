# 实验经验与结果边界

## 从输入到奖励的探索

1. 首先隔离官方 PPO 基线，Actor170→183、Critic292→305。箱子原有相对位置/线速度6维，补充姿态6D、角速度3D、尺寸3D、质量1D，共19维箱子信息。隐藏层与算法不变。
2. 尝试碰撞前相对速度、接触后减速及严重弹飞负奖励。中间实验见历史分支；这些负项在最终奖励实验中关闭，不能把中间实验结论当成当前运行配置。
3. 正向缓冲与 retain 奖励后，再尝试 C 版肩部动作范围和接箱姿态约束调整。C 包含动作空间和奖励变化，无法单独归因于某个奖励。
4. 根据“抱住后参考姿态恢复可能挤掉箱子”的观察，引入实际控制状态驱动的持续抱持，取消固定接箱年龄恢复。该机制已触发，但最终接稳率未提高；观察到竞争机制不等于证明所有掉箱的原因。

经验：中间控制时间和曾接住率提高，不代表最终保有成功提高。参考跟踪、AMP先验、动作范围、奖励门控都可能相互竞争。先保留同口径终局指标和原始分种子计数，再讨论下一步；目前增维600是这组测量中最终接稳率最高的基线。
